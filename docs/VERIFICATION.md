# Verification record

## Reproducible commands

- Clean lockfile installation: `npm ci --offline --cache /tmp/ledger-npm-cache` after populating that dedicated cache with the locked packages. Completed successfully; npm reported zero known vulnerabilities. A normal connected installation uses `npm ci`.
- `npm test -- --all --browser`: TypeScript strict checks, ESLint, **17 unit tests**, production build and the isolated Chrome browser workflow passed.
- `npm run build -- --base=/ledger/ --outDir=/tmp/ledger-prefix --emptyOutDir`: subpath production build passed.
- `npm run preview:local -- --base=/ledger/ --outDir=/tmp/ledger-prefix --port=3025 --strictPort`, then `npm test -- --browser --url=http://localhost:3025/ledger/`: the same browser workflow passed under `/ledger/`.
- `npm run licenses:generate`: collected complete license notices for 44 installed runtime packages. Notices are included in static output.

The scripts prefer `/usr/bin/google-chrome` when available, otherwise Playwright Chromium. Browser checks require a running preview server. Screenshots are regenerated by the browser workflow using demo/fixture records and a fixed test clock, not an existing user profile.

## Checked behavior

Unit cases cover exact cents, invalid input/limits, civil/leap dates, relative dates, immutable totals/sorting, inclusive filters, equal-day previous periods and zero denominators, complete-month budgets and overruns, legacy migration and raw recovery copies, failed recovery writes, unavailable storage, atomic backup validation, duplicate IDs/budget keys, incompatible categories, preference language, CSV quoting/formula-like text, and English/Italian phrase ambiguity.

The production-browser workflow covers:

- English-first startup despite an Italian browser locale; explicit demo and empty starts.
- Create, validation errors, edit, duplicate review, delete and undo.
- Description search, reset, results and CSV download content; no financial text in URLs.
- Budget creation, displayed overrun and explicit previous-month copying.
- Overview/Insights charts and Transactions navigation.
- Persistent Italian language after reload; switching back to English.
- Real JSON download, rejection of invalid JSON, validated preview and confirmed complete restore.
- Typed phrase preview/application without automatic saving.
- Legacy migration with the original recovery key retained; unsupported speech UI.
- A simulated browser recognition event for denied microphone permission.
- Corrupt persisted content left untouched with an original-export action.
- Desktop (1440 px), mobile (390 px) and tablet (820 px) widths without document overflow. Tables/navigation can scroll inside their own containers on narrow screens.
- Keyboard activation of entry, initial heading focus, tabbing into fields and keyboard submission.
- No JavaScript console/page errors, failed HTTP asset responses or external network requests in the primary workflow.

Real screenshots: `dashboard.png`, `transactions.png`, `budgets.png`, `mobile.png`, under `docs/screenshots/`. Desktop, mobile and budget captures were visually inspected.

## Practical limits

- **Real microphone recognition was not tested.** Parser tests, a mocked permission-error event and unsupported-browser handling were tested separately. No claim of offline voice support or universal phrase recognition is made.
- Tested in headless Google Chrome on Linux. Physical touch devices, Safari/Firefox, real speech services and a full screen-reader/contrast audit were not exercised.
- Storage and quota failures are simulated in unit tests. Browser data can be cleared, lost or separated by origin; export backups regularly. There is no encryption or synchronization.
- A static server is required to reopen the application. There is no service worker or installable/offline PWA promise.
- Demo data is fictional and deterministic, covering July–November 2026. It is not financial advice or a bank statement. Legacy categories require explicit review before contributing to totals.
- CI is prepared locally, with no deployment job; it has not run on a remote repository. No repository was created remotely, and no push or deploy was performed.
